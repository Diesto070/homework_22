### I. Знакомство с Django
**Задание 1. Настройка проекта**

1. Создаем новую директорию для проекта и настраиваем виртуальное окружение.
2. Инициализируем новый проект Django внутри этой директории.

Не забываем про добавление файла ```.gitignore```
 и правила ведения разработки по GitFlow. Создаем ветки ```main```, ```develop``` и отдельные ветки для решения заданий. Также не забываем оформить файл README с описанием проекта.

**Задание 2. Создание и настройка приложения**

1. Создаем новое приложение под названием ```catalog``` в нашем проекте.
2. Зарегистрируем приложение в настройках проекта.
3. Настроем маршрутизацию для нового приложения, добавив соответствующие URL-адреса.

**Задание 3. Создание шаблонов**

1. Подготовим два HTML-шаблона: для домашней страницы и для страницы с контактной информацией.
2. Для стилизации страниц используем Bootstrap.

Можно взять за основу следующие шаблоны:

**Задание 4. Реализация контроллеров**

1. Создаем контроллер для отображения домашней страницы.
2. Создаем контроллер для отображения страницы с контактной информацией.
3. Настраиваем маршрутизацию для этих контроллеров.


* Дополнительное задание
1. Реализуем форму обратной связи на странице контактов.
2. Настраиваем обработку данных формы в контроллере, чтобы отображать сообщение об успешной отправке данных.

### II. 23 Работа с ORM в Django
**Задание 1**
Подключаем СУБД PostgreSQL для работы в проекте.

1. Создаём базу данных в ручном режиме.
2. Вносим изменения в настройки подключения в файле ```settings.py```.

**Задание 2**
В приложении каталога создаем модели ```Product``` и ```Category``` и описываем для них базовые настройки.

**_Описание моделей:_**
1. ```Product```:
    - наименование,
    - описание,
    - изображение,
    - категория,
    - цена за покупку,
    - дата создания,
    - дата последнего изменения.
2. ```Category```:
   - наименование,
   - описание.

**Задание 3**
Переносим отображение моделей в базу данных с помощью инструмента миграций. Для этого:
- создайте миграции для новых моделей;
- примените миграции.

**Задание 4**
1. Создаем суперпользователя.
2. Зарегистрируем модели ```Product``` и ```Category``` в админке.
3. Настраиваем отображение для моделей:
Для ```Category``` выведите ```id``` и ```name``` в списке.
Для ```Product``` выведите ```id```, ```name```, ```price``` и ```category``` в списке.
Настройте фильтрацию продуктов по категории.
Настройте поиск по полям ```name``` и ```description```.

**Задание 5**
Через инструмент shell заполните список категорий, а также выберите список категорий, применив произвольные рассмотренные фильтры.

1. Войдите в Django shell.
2. Создайте несколько категорий и продуктов.
3. Выполните следующие запросы:
   * Получите все категории.
   * Получите все продукты.
   * Найдите все продукты в определенной категории.
   * Обновите цену для определенного продукта.
   * Удалите продукт.

**Задание 6**
Сформируйте фикстуры для моделей ```Category``` и ```Product```.

**Задание 7**
1. Создайте кастомную команду для добавления тестовых продуктов.
2. В команде удалите все существующие данные из базы перед добавлением новых продуктов.
