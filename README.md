### V. 26.1 Формы 
**Задание 1**
Реализован механизм CRUD для модели продуктов, используя модуль ```django.forms```. При этом  обезопасили сайт от спама и не разрешено присваивать продуктам названия и добавлять в описание слова, которые включены в список запрещенных слов.

Реализована валидация формы, чтобы проверять отсутствие этих слов (в любом регистре) в данных полях.

Запрещенные слова, которые нельзя использовать в названиях и описаниях продуктов:

   казино,
   криптовалюта,
   крипта,
   биржа,
   дешево,
   бесплатно,
   обман,
   полиция,
   радар.

**Задание 2**
Добавлена кастомная валидация для поля 
```purchase_price``` в форме создания и редактирования продуктов. Валидация проверяет, что цена продукта не может быть отрицательной. Реализовано это с использованием метода ```clean_price``` в форме. Если цена введена неправильно, отображается соответствующее сообщение пользователю.

**Задание 3**
Добавлена стилизация форм для продуктов, используя метод ```__init__```. 


Реализован механизм, при котором пользователи могут загружать изображения продуктов. Добавлена валидация для поля загрузки изображения, чтобы проверить формат и размер загружаемого файла. Также проверка на то, что загружаемые файлы имеют формат JPEG или PNG и не превышают размер 5 МБ.
